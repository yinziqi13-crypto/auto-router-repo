## 交付内容

### 一、后端接口 GET /router/stats
**文件**：`router/db.py`（新增 `parse_time_range()` + `query_stats()`）
**文件**：`router/main.py`（新增 `get_stats()` 端点）

**功能**：
- 从 `router_decision_event` 表只读统计，不影响路由
- `time_range` 参数：`1h`/`6h`/`24h`(默认)/`7d`
- 返回字段全齐：
  - 汇总：`total_requests` / `success_count` / `fail_count` / `success_rate`
  - free/paid：`free_count` / `paid_count` / `free_ratio`
  - 分布：`provider_distribution` / `model_distribution` / `task_type_distribution`
  - 性能：`avg_latency_ms` / `fallback_count`
  - 时序：`hourly_requests`（24 个桶，空桶补 0）

**查询实现**：
- 汇总：1 条 `SELECT COUNT/SUM/AVG` 搞定
- 分布：3 条 `GROUP BY` 查询
- 时序：`substr(created_at,1,13)` 按小时分组，Python 侧补空桶

### 二、HTML 看板页面 GET /dashboard
**文件**：`router/static/dashboard.html`

**技术选型**：纯 HTML + Chart.js v4 CDN，无框架，无构建工具
**页面结构**：
- 顶部 4 个 KPI 卡片：总请求数 / 成功率 / Free 占比 / 平均延迟
- 中间 3 个饼图：渠道分布 / 模型分布 / 任务类型分布
- 底部折线图：最近 24 小时请求量趋势（UTC 小时桶）
- 右上角：time_range 下拉 + 刷新按钮
- 暗色主题（#0f172a 背景），配色 Chart.js 默认

**安全**：仅监听 127.0.0.1，无登录（M0 防火墙保证外部不可访问）
