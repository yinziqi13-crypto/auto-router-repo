## 交付内容

### 一、providers.py（新增）
**文件**：`router/providers.py`

**Provider ABC**（抽象基类）：
- `forward(token, request, model_mapping) → {status_code, headers, body, error, latency_ms}`
- `forward_stream(token, request, model_mapping) → AsyncGenerator[bytes]`
- `health_check() → bool`

**NewAPIProvider**（实现，继承 httpx.AsyncClient）：
- 构造：`base_url`（New API 地址）
- `forward()`：构造 upstream URL `base_url/v1/chat/completions`，带 Bearer token，处理 connection_fail / timeout / 非 200
- `forward_stream()`：用 `httpx.AsyncClient.stream()` 透传 SSE 字节流
- `health_check()`：简单 GET base_url/health（200 或 404 都算可用）
- `_resolve_model()`：`model_mapping.get(model, model)`（兼容 M1-1 逻辑）

**ProviderRegistry**（注册表，单例）：
- `init_from_config(providers_config, default_base_url)`：读 config.json 的 `providers` 字段，注册 Provider 实例
- `get(name) → Provider | None`
- `get_default() → Provider | None`
- `all() → Dict[str, Provider]`
- `close_all()`：关闭所有 provider 的 httpx client

### 二、adapter.py 重构
**文件**：`router/adapter.py`

- `NewAPIAdapter` 改为继承 `NewAPIProvider`（不再自己实现 forward）
- 保留 `classify_error()` 方法（向后兼容 decision.py 旧代码引用）
- 类名不变（`NewAPIAdapter`），decision.py import 无需改动

### 三、decision.py 改造
**文件**：`router/decision.py`

- `__init__` 新签名：`(state_manager, config, db_conn=None, adapter=None, provider_registry=None)`
  - 优先用 `provider_registry`，向后兼容传 `adapter`（自动注册到内部 registry）
- 新增 `_provider_transport: Dict[str, str]`：`provider_name → transport_name` 映射（当前所有 provider 走 `new_api`）
- 新增 `_get_provider(provider_name)`：查映射 → registry.get(transport) → fallback get_default()
- `route()` 三处 forward 调用全部改成 `self._get_provider().forward()`

### 四、main.py 改造
**文件**：`router/main.py`

- startup：用 `ProviderRegistry.init_from_config()` 初始化，传 `provider_registry` 给 `DecisionEngine`
- shutdown：`provider_registry.close_all()` 替代 `adapter.close()`
- 流式分支：`decision_eng._get_provider()` 拿 provider 实例 → `provider.forward_stream()`
- `/health` 版本号：`M2-6`

### 五、models.py 新增字段
**文件**：`router/models.py`

- `RouterConfig.providers: Optional[Dict[str, Dict[str, Any]]]`（config.json 的 providers 配置）

1. 当前所有 provider（tencent_free / bailian_free / bailian_lite / tencent_plan）都走同一个 `new_api` transport（M3 接直连上游时增加新 transport）
