### 🔬 核心发现（今日最重要结论）

```
New API rc.30 渠道路由机制（DB 直查模式，M0 默认）
─────────────────────────────────────────────
1. 候选池索引：group → model → [channel_id]
   → base_url 不参与分组，不同 base_url 可进同一候选池 ✅

2. 路由依据表：abilities（非 channels）
   → abilities.priority / abilities.weight 决定选择
   → 改 channels 表的 priority 不会自动同步 abilities ⚠️

3. priority 语义：
   retry=0 → 最高 priority 渠道组
   retry=1 → 第二高 priority 组（需第一次调用失败触发）
   → 同一 priority 组内按 weight 加权随机

4. M0 容器无 MEMORY_CACHE_ENABLED=true
   → 走 DB 直查（GetChannel in ability.go）
   → 改 abilities 表后立即生效，无需重启 ✅
```
