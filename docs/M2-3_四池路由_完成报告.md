## 一、M2-3 目标

让 Auto Router 能根据请求内容判断任务类型，按任务类型选模型，再走 free 优先 + paid 降级的现有逻辑。  
对应 4 个 provider（tencent_free / bailian_free / bailian_lite / tencent_plan）。

## 二、代码改动

### 1. models.py — 新增配置字段
- `RouterConfig` 新增 `routing_strategy: str = "cost_optimized"`（路由策略，当前只实现 cost_optimized）
- `RouterConfig` 新增 `model_routes: Dict[str, Optional[str]]`（任务类型 → 推荐模型名映射）
  - 示例：`{"text": "deepseek-v4-flash", "vision": null, "audio": null, "image": null}`
  - null / 缺失 → fallback 到 model_routes["text"] → 仍缺失则保留 original_model
- `three_pool_keywords` 注释更新（补全 10-15 个中英文关键词示例）

### 2. decision.py — 任务类型检测升级
- **新增常量** `DEFAULT_TASK_KEYWORDS`（每类 10-15 个中英文关键词，内置默认值）
- **新增常量** `DETECTION_ORDER = ["image", "video", "audio", "vision"]`（生成类先于理解类，防止"生成图片"误判为 vision）
- **重写 `_detect_task_type()`**：
  - 合并 `DEFAULT_TASK_KEYWORDS` + `config.three_pool_keywords`（config 同名类别覆盖追加）
  - 按 `DETECTION_ORDER` 优先级检测
  - **未命中任何关键词 → 返回 `TaskType.TEXT`（默认文本）**（原为 UNKNOWN，按你要求改为 TEXT）
- **新增 `_resolve_route_model()`**：
  - 根据 `task_type` 从 `config.model_routes` 拿推荐模型名
  - `model_routes[task_type]` 为 null/缺失 → fallback 到 `model_routes["text"]`
  - `model_routes["text"]` 也缺失 → 保留 `original_model`（向后兼容）
  - `routing_strategy` 非 `cost_optimized` 时记日志，按 cost_optimized 行为兜底（balanced / quality_optimized 占位）

### 3. decision.py — decide() / route() 路由逻辑改造
- `logical_model = request.model` 改为 `logical_model = self._resolve_route_model(task_type, request.model)`
- `route()` 里构造 `forward_req`（model = logical_model），三处 `adapter.forward()` 均改用 `forward_req`
- `decide()` 返回的 `RouterDecisionEventRecord.logical_model` 现在是推荐模型名（非原始模型名）

### 4. main.py — 流式转发模型名修正
- 流式分支构造 `stream_req = ChatCompletionRequest(model=decision.logical_model, ...)`（原用 `chat_req.model` 原始名）
- `_stream_generator()` 里 `adapter.forward_stream()` 改用 `stream_req`

## 七、注意事项

1. **vision/image 检测边界**：`three_pool_keywords` 的 `vision` 类含"图片"、"图像"等词，`image` 类含"画图"、"生成"等词；`DETECTION_ORDER` 设定 image 先于 vision，防止"生成一张图片"误判为 vision
2. **model_routes 为 null 时的行为**：vision/audio/image 的推荐模型为 null → fallback 到 text 模型 → 仍走 free 优先逻辑（不会跳过 free 池）
3. **流式转发的模型名**：之前流式用原始 `chat_req.model`，现在改为 `decision.logical_model`（与 route() 非流式行为一致）
4. **config.json 路径陷阱**：同 M2-2 记录，`router.db` 在 `/opt/ai-hub/auto-router/router/router.db`
